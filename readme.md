# Tool_generator_python_2025
Применимость: CREO Parametric 8 и выше
Назначение: создание xml файлов с параметрами инструментов по каталожным значениям

## Как пользоваться
-1. перейти в ветку разработки, чтобы не испорить рабочие файлы.
    - git checkout dev
0. Настроить в файле src\tool_updater\config.py
    - abs_path_to_dir_where_to_create_tool_xmls
    - abs_path_to_dir_where_project_is_located
1. Найти pdf каталог нужного производителя металлорежущего инструмента в интернете.
2. Найти интересующую серию инструмента, таблицу с геометрией инструмента и таблицу с режимами резания.
3. скопировать всю таблицу геометрии данной серии инструмента в первый новый файл geom_data.json
4. скопировать всю таблицу режимов резания для данной серии во второй новый файл cut_data.json
5. положить данные файлы в директорию src\tool_updater\catalogs\<класс инструмента>\<тип инструмента>\<производитель инструмента>\<серия инструмента>
6. отформатировать содержимое файлов под .json 
    - в папке src\tool_updater\catalogs лежат примеры .json для
7. в файле src\tool_updater\main.py в функции main() расскомментировать вызов нужной функции (функции каждая запускает генерацию своего типа инструмента)
8. в теле функции нужного класса дописать дополнительно вызов ToolGenerator, скопировав существующий вызов и изменив пути, имена
9. открыть терминал bash, выполнить команду

```bash
python -m src.tool_updater.main
```

10. проверить сгенерированные файлы. Если всё ок, то..
11. закоммитить изменения
    - git add .
    - git commit -m 'комментарий, что было изменено'
