# Безопасный пример генерации

Требования: Windows и Python 3.12 или новее. Сторонние пакеты не нужны.

Из корня репозитория выполните:

```bash
python -m src.tool_updater.demo
```

В этой рабочей копии корень проекта:
`d:/PROJ/CREO_tool_xml_generator`.
При переносе проекта команда не требует изменения путей.

## Входные данные

- `geometry.json`: один искусственный инструмент диаметром 6 мм.
- `cut_data.json`: искусственные режимы для шести групп ISO.

Это учебные значения, а не рекомендации для обработки на станке.
Данные не взяты из каталога производителя.

## Результат

XML записывается в каталог `generated_xmls/demo` от корня проекта.
Журнал дополняется в `src/logs/log.log` от корня проекта.
Оба каталога исключены из Git.

Генератор сначала пишет XML во временную подпапку. Demo проверяет,
что создан ровно один XML и что XML-парсер может его прочитать.
Затем файл переносится в итоговый каталог. Повторный запуск заменяет
одноимённый demo-файл. Остальные файлы не удаляются.

Demo не использует производственные пути записи из конфигурации.
Расчёты используют существующий класс BallMill и общие настройки проекта.
Производственный запуск через main по-прежнему требует настройки путей.

## Ограничения

- Существующий метод записи XML требует Windows.
- Проверка XML-парсером не подтверждает совместимость с CREO.
- В XML есть ссылки на модели сборок из существующего класса BallMill.
  Эти модели не поставляются с примером.
- Не используйте результат для обработки на станке.
